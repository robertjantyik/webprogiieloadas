# Reszponzív téma

**Téma:** Start Bootstrap - Shop Homepage  
**Forrás:** https://startbootstrap.com/template/shop-homepage  
**Forráskód:** https://github.com/StartBootstrap/startbootstrap-shop-homepage  
**Licenc:** MIT (a licencszöveg a `LICENSE.txt` fájlban található)

A projekt a Start Bootstrap Shop Homepage ingyenes, Bootstrap-alapú üzleti oldalának elrendezési ötleteit és a Bootstrap reszponzív navigációját használja. A fejlécet, az oldalszerkezetet és a notebook-katalógus megjelenítését a ReNew projekthez igazítottuk; a notebook-adatok és az alkalmazás működése saját Laravel Blade nézetekből származik.

A Bootstrap 5.3.3 CSS és JavaScript a `resources/views/layout.blade.php` fájlban CDN-ről töltődik be. Hálózati kapcsolat nélkül az oldal működési logikája megmarad, de a Bootstrap reszponzív stílusai és mobil navigációs összecsukása nem töltődnek be.
